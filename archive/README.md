# Lưu trữ: bản 6 bước cũ (08/2026 – 10/2026)

Đây là quy trình cũ của series, dùng trước khi Arc Studio có bước Plan. Hồi đó phải tự đi 6 bước: lên ý tưởng → viết PRD → để AI phỏng vấn ngược và chốt stack → vẽ wireframe → setup môi trường → build 3 giai đoạn.

Từ 10/2026 series rút còn 4 bước (xem [README chính](../README.md)), vì Arc Studio đã tự lo phần lên kế hoạch, chọn stack, dựng bản demo và deploy lên testnet.

Vẫn giữ lại đây vì hai lý do:

- Bảng **"Prompt này từng hụt chỗ nào"** ở từng bước là kinh nghiệm có thật, xoá đi là mất. (Mục "Ví dụ" TapTip/EZwallet đã gỡ 10/2026 vì cũ.)
- Cần làm kỹ hơn (app đụng nhiều tiền, nhiều màn, team đông) thì các prompt cũ vẫn dùng được, nhất là phỏng vấn ngược ở [`03-planning`](03-planning/README.md) và luật lưới ở [`04-wireframe`](04-wireframe/README.md).

| Bước cũ | Nội dung |
|---|---|
| [`01-ideation`](01-ideation/README.md) | 6 hướng Arc, 3 câu: đúng đối tượng, có điểm hơn, khả thi |
| [`02-hoan-thien-y-tuong`](02-hoan-thien-y-tuong/README.md) | 6 câu PRD + core value |
| [`03-planning`](03-planning/README.md) | Phỏng vấn ngược UX/logic/lỗi/bảo mật + chốt stack từng luồng |
| [`04-wireframe`](04-wireframe/README.md) | Wireframe trên hệ lưới, chữ bội số 3, khoảng cách bội số 8 |
| [`05-setup`](05-setup/README.md) | Setup môi trường, nối GitHub, cài đúng stack |
| [`06-build`](06-build/README.md) | Build 3 giai đoạn: logic → giao diện → live và sửa theo người dùng |

Các file này không còn được cập nhật.
